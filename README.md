## Theories & Implementations

### Global Workspace Theory (GWT)
*Bernard Baars, 1988*

Information becomes conscious when broadcast to a "global workspace" accessible by multiple specialized processors.

- [Deep learning and the Global Workspace Theory](https://pubmed.ncbi.nlm.nih.gov/34001376/) - Roadmap for GWT + deep learning
- [A Case for AI Consciousness: Language Agents and GWT](https://arxiv.org/abs/2410.11407) - LLMs and GWT

### Integrated Information Theory (IIT)
*Giulio Tononi, 2004*

Consciousness corresponds to integrated information (Φ). Systems with high Φ are highly conscious.

- [IIT 4.0 Paper](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011465) - Latest formulation
- [PyPhi Documentation](https://pyphi.readthedocs.io/) - Compute Φ values

### Higher-Order Theories (HOT)
Consciousness requires meta-cognitive awareness of mental states.

### Predictive Processing
The brain (and potentially AI) as a prediction machine minimizing surprise.

### Strange Loops & Self-Reference
*Douglas Hofstadter*

Consciousness emerges from self-referential feedback loops.
